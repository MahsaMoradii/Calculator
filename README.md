    # 🧮 ماشین حساب

این پروژه یک **ماشین حساب ساده و کاربردی** است که با استفاده از **HTML، CSS و JavaScript** طراحی و پیاده‌سازی شده است. هدف از ساخت این پروژه، تمرین مفاهیم پایه جاوااسکریپت، مدیریت رویدادها (Events) و پیاده‌سازی عملیات‌های ریاضی در محیط وب بوده است.

## ✨ امکانات

- انجام چهار عمل اصلی ریاضی (جمع، تفریق، ضرب و تقسیم)
- رابط کاربری ساده و کاربرپسند
- نمایش لحظه‌ای اعداد و نتایج
- دکمه پاک کردن (Clear)
- محاسبه نتیجه با دکمه مساوی (=)
- پیاده‌سازی منطق ماشین حساب با JavaScript

## 🛠️ تکنولوژی‌های استفاده شده

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🎯 هدف پروژه

این پروژه با هدف تقویت مهارت‌های فرانت‌اند، آشنایی بیشتر با JavaScript و پیاده‌سازی منطق برنامه‌نویسی در یک پروژه کاربردی توسعه داده شده است.

## 🚀 نحوه اجرا

1. پروژه را دانلود یا Clone کنید.
2. فایل `index.html` را در مرورگر اجرا کنید.
